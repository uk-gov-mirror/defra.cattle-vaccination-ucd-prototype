{# Named for what the vet does, not for which version it is. A participant should be choosing between three ways of working, not between three build numbers. Check data comes first because it is the question that decides the rest: most tests arrive as a file from a handheld, and only the remainder are typed in from paper. The three below are what the typing looks like. #}

1.Check data

Start with how the test was recorded. A file from a handheld goes to a screen for checking and correcting what arrived; paper forks again by what is being recorded – a whole herd, or a few named cattle.

2.One page radio

The whole herd on one page. Every animal is a row with Clear, Reaction or Not tested, and the readings open on the row you pick.

3.Add another

The herd is never listed. Name each animal that reacted, record its readings, then add another. Anything you do not name is reported as tested with no reaction.

4.Tick and type

Tick the cattle that reacted, then type their readings. Then a second pass for the cattle that were not tested, and why.
